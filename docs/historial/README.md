## Regla de archivo

Un plan pasa aquí cuando sus decisiones ya están ejecutadas o refutadas, y su
valor es histórico (entender POR QUÉ el sistema es como es). Nunca se edita
un plan archivado para "actualizarlo": se escribe uno nuevo y se archiva el
viejo tal cual.
